# 🌻 Flores Amarillas - 21 de Septiembre 💛

Un sitio web estático interactivo y romántico creado para celebrar la hermosa tradición del **21 de Septiembre** regalando flores amarillas que nunca se marchitan.

---

## ✨ Características Principales

1. **Ramo de Flores Amarillas Animado (SVG):**
   - Tallos que brotan y crecen al cargar la página.
   - Hojas que florecen con animaciones orgánicas y un lazo dorado.
   - Girasol principal y flores acompañantes con pétalos detallados y centros dorados.
   - Efecto suave de balanceo con el viento y resplandor mágico (*glow*).

2. **Lluvia de Pétalos y Luciérnagas (Canvas 2D):**
   - Pétalos de flores amarillas que caen, giran en 3D y oscilan con el viento.
   - Partículas de luciérnagas titilantes en el fondo.

3. **Carta Personalizada Interactiva:**
   - Botón con resplandor para abrir una carta/tarjeta vintage con sello de cera de girasol.
   - Dedicatoria y mensaje especial para este 21 de septiembre.

4. **Cajita Musical Integrada (Web Audio API):**
   - Reproduce la melodía inspirada en el clásico *"Flores Amarillas"* sintetizada en tiempo real sin necesidad de archivos de audio externos (funciona 100% offline y sin problemas de CORS).

5. **Personalización y Enlaces Compartibles:**
   - Puedes ingresar el nombre de la persona (`Para: ...`), tu nombre (`De: ...`) y un mensaje personalizado.
   - Genera automáticamente un enlace listo para copiar y enviar por WhatsApp o redes:  
     `index.html?para=Sofia&de=Carlos&msg=Mensaje`

6. **Interacción al Clic / Toque:**
   - Toca cualquier parte de la pantalla para hacer brotar flores y destellos dorados con notas musicales.

7. **Selector de Tema:**
   - Modo **Noche Estrellada** 🌙 y modo **Atardecer Dorado** 🌅.

## 🚀 Cómo Usarlo

### 1. Abrir Localmente
Solo haz doble clic en el archivo [index.html](file:///C:/Users/home/OneDrive/Escritorio/21%20de%20septiembre/index.html) para abrirlo en tu navegador favorito (Chrome, Edge, Firefox, Safari).

### 2. Publicar en GitHub Pages
Como este repositorio ya está configurado con Git:
1. Sube los cambios con:
   ```bash
   git add .
   git commit -m "feat: Sitio de flores amarillas interactivo"
   git push origin main
   ```
2. En tu repositorio de GitHub, ve a **Settings > Pages**.
3. Selecciona la rama `main` y guarda. En segundos tendrás un enlace público para compartir.
